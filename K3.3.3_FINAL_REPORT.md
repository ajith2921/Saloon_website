## 15. Remaining Manual Steps
To make the deployment live, you MUST perform these external actions:
1. Push the `render.yaml` to GitHub.
2. In the Render Dashboard, connect this repository to create a **Blueprint Instance**.
3. In the Render Dashboard -> Environment Variables, input your real `SUPABASE_*` and `RAZORPAY_*` test secrets.
4. Copy the resulting `https://your-app.onrender.com` URL.
5. In the Razorpay Webhooks Dashboard, add the webhook endpoint: `https://your-app.onrender.com/api/webhooks/razorpay` using your mapped webhook secret.
6. Open your Supabase SQL editor and execute migrations `005` and `006`.
